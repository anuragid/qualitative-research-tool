V3 fixes:
  • Thumbnails hidden by default — clip-path on the container hides them behind the front panel
  • Front panel tilts toward you — rotateX(-12deg) with transform-origin: bottom center. Top edge comes forward, bottom stays anchored
  • Clip-path removed on hover so thumbnails can escape and fan out above the folder
  • The front panel stays in place — no translateY, no sliding down
