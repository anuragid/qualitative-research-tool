Folder Micro-Interaction

Three approaches for the hover reveal animation. Each uses your brand colors, shows up to 3 video thumbnails (most recent first), and uses design system tokens. Hover each folder to see the animation.

Approach A — Recommended
Front-Flap Lift
Front panel tilts open via CSS perspective, revealing thumbnails that fan upward from inside. Closest to your reference image 1.

Strengths

  • Most faithful to reference
  • Physical/tactile feel
  • 3D depth via CSS perspective
  • Thumbnails emerge naturally

Trade-offs

  • Perspective can clip on grid edges
  • Needs overflow:visible on parent

Approach C
Gentle Peek
Subtler version: front panel tilts less, thumbnails peek up gently. More restrained, closer to Craft's quiet sophistication.

Strengths

  • Most subtle/restrained

Trade-offs

  • Less dramatic reveal
  • Thumbnails harder to see
  • May feel underwhelming
My recommendation: Approach A (Front-Flap Lift). It's the most faithful to your reference image — the front panel tilts open with CSS 3D perspective, and thumbnails fan upward from inside. It has the strongest "physical folder" feel while keeping things CSS-only (no JS animation libs needed for the core interaction). The brand color becomes the folder's identity, and the noise texture carries through.
