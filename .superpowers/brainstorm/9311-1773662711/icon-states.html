Folder Icon States

The bottom-left badge on the front panel acts as a glanceable status indicator. Each project state gets a distinct icon + animation treatment. All colors from the design system.

Project Lifecycle
The icon reflects where the project is in its journey — from creation to completion.
planning
Empty / Planning
Plus icon invites adding content. Subtle, non-animated.
ready
Ready
Play icon — videos uploaded, ready to analyze. Static.
processing
Processing
Spinning arc + pulsing ring. Active, alive — analysis is running.
completed
Completed
Checkmark bounces in, stroke draws. Settles to static after first view.
error
Error
Exclamation mark shakes on first appearance. Red background demands attention.
archived
Archived
Entire folder dims. Archive icon. No animation — dormant.
Processing Sub-States
When analysis is running, the icon can communicate which phase. These cycle automatically as the pipeline progresses.
transcribing
Transcribing
Mic icon with pulse. Audio → text conversion in progress.
analyzing
Analyzing
Spinning sun/gear with teal accent. AI is thinking through the data.
synthesizing
Synthesizing
Network nodes connecting. Cross-video patterns being discovered.
Design Principles

Glanceable: You should know the state without reading text. The icon + color combination is enough.

Animated only when active: Only processing states animate. Completed/ready/archived are static. No gratuitous motion.

Respects reduced motion: All animations collapse to static states with prefers-reduced-motion.

One-time transitions: Completion checkmark draws once on first view, then stays static. Error shakes once, then stays. No infinite loops for settled states.

Colors from the design system: Info blue for processing, success green for completed, destructive red for error, brand accent teal for AI-specific phases, neutral for planning/archived.
